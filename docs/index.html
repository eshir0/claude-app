설치

처음 설치하기

필요한 것: Node.js 24 이상, 리눅스 서버 하나. 순서대로 따라오시면 됩니다.

  1. 저장소 받고 설치 
    git clone https://github.com/eshir0/claude-app.git
cd claude-app
npm install
  2. 환경변수 파일 만들기 
    cp .env.example .env

    그다음 아래 환경변수 설명을 보면서 .env를 채웁니다.

  3. 로그인 비밀번호 만들기 
    npm run hash-password

    화면에서 비밀번호를 직접 입력하면(입력값은 화면에 안 보임) bcrypt 해시가 출력됩니다. 이 값을 .env의 AUTH_PASSWORD_HASH에 붙여넣으세요.

    주의: .env 파일은 $ 기호를 특별하게 해석합니다. bcrypt 해시는 $2b$12$...처럼 $가 여러 번 들어가므로 매번 앞에 역슬래시를 붙여야 합니다: \$2b\$12\$.... npm run hash-password 출력값은 이미 이렇게 되어 있으니 그대로 복사하면 됩니다.

  4. 데이터베이스 준비 
    npx prisma migrate dev
  5. 실행 
    npm run dev
# 또는 계속 켜둘 거라면
npm run build && npm run start

    브라우저에서 http://localhost:3000 (또는 .env의 APP_ORIGIN에 적은 주소)로 접속합니다.

연결 1

ChatGPT/Codex 연결하기

  1. 이동

    로그인 후 /ai-usage/connections로 이동

  2. 연결하기 클릭
  3. 링크와 코드 확인

    화면에 링크와 한 번 쓰는 코드(예: ZNLX-BJ8PO)가 뜹니다.

  4. 본인 기기에서 로그인

    휴대폰이나 PC 브라우저에서 그 링크를 열고 ChatGPT 계정으로 로그인한 뒤 코드를 입력합니다.

  5. 자동 완료

    화면이 자동으로 "연결됨"으로 바뀝니다.

비밀번호나 쿠키를 직접 붙여넣지 않습니다. OpenAI의 공식 로그인 방식(기기 코드 로그인)을 그대로 쓰고, 로그인은 항상 본인 브라우저에서 이뤄집니다. 이 서버는 로그인 결과만 암호화해서 저장합니다.

Claude(Anthropic)는 왜 지원 안 하나요? Anthropic이 2026년 2월 약관을 바꿔서, Claude Pro/Max 구독 로그인 정보를 서드파티 서비스에서 쓰는 것을 공식 금지했습니다. 그래서 이 기능은 만들지 않았습니다.

연결 2

Proxmox 연결하기

Proxmox 웹 UI에 로그인한 상태에서 진행합니다.

  1. Datacenter 클릭

    왼쪽 트리에서 Datacenter를 클릭합니다.

  2. API Tokens로 이동

    Permissions → API Tokens를 클릭합니다.

  3. Add 클릭
  4. 토큰 정보 입력

    User는 기존 계정 그대로(root@pam 등), Token ID는 원하는 이름(예: dashboard), Privilege Separation은 체크 해제합니다.

  5. Token ID / Secret 복사

    Add를 누르면 뜨는 두 값을 복사해둡니다. Secret은 이 화면을 닫으면 다시 볼 수 없습니다.

  6. 서버 지문값 확인 
    curl -k https://<Proxmox 주소>:8006/api2/json/nodes

    결과에서 ssl_fingerprint 값을 복사합니다.

  7. .env에 채우기 
    PROXMOX_URL=https://<Proxmox 주소>:8006
PROXMOX_TOKEN_ID=<4번의 User>!<4번의 Token ID>
PROXMOX_TOKEN_SECRET=<5번의 Secret>
PROXMOX_SSL_FINGERPRINT=<6번의 ssl_fingerprint>

지문값을 등록해두는 이유는, 접속할 때마다 "지금 접속한 서버가 진짜 내 Proxmox가 맞는지" 확인하기 위해서입니다. Proxmox 인증서는 공인 기관 서명이 아니라 자체 서명이라, 지문을 고정해두지 않으면 중간에서 누군가 가로채도 알아챌 방법이 없습니다.

선택

온도 모니터링 설정하기 (선택)

Proxmox의 API 자체에는 온도 정보가 아예 없습니다. 그래서 API 토큰이 아니라 SSH로 호스트에 직접 접속해 sensors 명령을 읽어오는 다른 방식을 씁니다. 설정 안 해도 나머지 기능은 전부 정상 작동합니다.

  1. 전용 SSH 키 만들기

    이 앱을 실행하는 서버에서:

    ssh-keygen -t ed25519 -f ~/.ssh/proxmox_dashboard_ed25519 -N ""
cat ~/.ssh/proxmox_dashboard_ed25519.pub
  2. Proxmox 웹 UI → Shell에서 키 등록하기

    왼쪽 트리에서 노드 클릭 → 오른쪽 위 >_ Shell 클릭. <공개키> 자리에 1번 결과를 통째로 넣고 실행:

    mkdir -p ~/.ssh && chmod 700 ~/.ssh
echo 'command="sensors -j",no-port-forwarding,no-X11-forwarding,no-agent-forwarding,no-pty <공개키>' >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys

    command="sensors -j"가 핵심입니다 — 이 키로는 sensors -j 명령 말고는 아무것도 실행할 수 없게 강제로 제한합니다. 앱에 문제가 생기거나 키가 유출돼도 "온도 조회" 이상은 못 합니다.

  3. lm-sensors 설치 확인

    같은 Shell에서:

    which sensors || (apt update && apt install -y lm-sensors && yes | sensors-detect --auto)
sensors -j

    JSON이 나오면 성공. 하드웨어에 따라 팬 속도처럼 일부 값은 애초에 안 잡힐 수 있는데, 그런 값은 억지로 만들어내지 않고 그냥 표시하지 않습니다.

  4. .env에 채우기 
    PROXMOX_SSH_HOST=<Proxmox 호스트의 LAN IP, 예: 192.168.1.24>
PROXMOX_SSH_KEY_PATH=/home/유저/.ssh/proxmox_dashboard_ed25519

    PROXMOX_URL(포트포워딩된 공인 주소)과 달리, 이건 LAN 안에서 직접 접속하는 IP를 씁니다 — Proxmox 웹 UI의 Datacenter → 노드 → System → Network에서 확인할 수 있습니다.

참고

알아두면 좋은 점

  • HTTPS가 아직 없습니다. 지금은 평문 HTTP입니다. 집 안(LAN)에서만 쓰면 크게 문제없지만, 공인 IP로 포트포워딩해서 인터넷에 열어두면 로그인 비밀번호와 세션이 암호화 없이 오갑니다. 계속 공개로 열어두실 거면 도메인을 마련해 HTTPS(리버스 프록시 + Let's Encrypt)를 붙이는 걸 권장합니다.
  • 재부팅하면 자동으로 다시 켜지지 않습니다. 지금은 사람이 직접 실행해야 합니다. 계속 켜두고 쓰실 거면 systemd 서비스 등록을 추천합니다.
  • AI 사용량은 이력이 쌓이지만, 서버(Proxmox) 상태는 실시간 값만 보여주고 따로 저장하지 않습니다. Proxmox 자체가 이미 자기 이력을 갖고 있어서입니다.
